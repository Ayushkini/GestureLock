# Security Policy

GestureLock is a learning prototype, not a production access-control system.

## Reporting a concern
Please open a GitHub issue for non-sensitive bugs. Do not post real passwords, private network information, or personal data.

## Security limitations
- The access point password is a demo default and should be changed.
- The dashboard uses local HTTP.
- Gesture sequences are not a substitute for cryptographic authentication or certified physical security.
- Do not deploy this project to protect valuables or safety-critical areas.
