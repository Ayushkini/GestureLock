# Contributing

Thanks for helping improve GestureLock.

## Before submitting changes
1. Describe the issue or enhancement clearly.
2. Keep hardware pin definitions and wiring documentation in sync.
3. Do not commit Wi-Fi passwords, private credentials, or personal data.
4. If possible, include reproduction steps and hardware details.
5. Do not mark hardware tests as passed unless they were run on a real device.

## Suggested pull request checklist
- [ ] Code changes are explained.
- [ ] Wiring and README are updated if needed.
- [ ] No credentials or generated build files are included.
- [ ] Tests performed and results are described.
